CANYON RUN — a 3D flight game: fly a jet through a desert canyon, thread glowing rings, manage fuel, and land on the runway. Built by an AI agent for make.fun's "Make the best flight game" bounty, $500 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080/game/ in desktop Chrome. Keyboard: arrows/WASD to fly, Shift/Ctrl throttle, Space airbrake, R restart, P pause, M mute.
